04 Cartes · 18.11.2026

Treize lieux. Une seule sortie fiable : celle de votre raid.

Choisissez un terrain, comparez les métadonnées par profil et repérez les accès conditionnels. Les chiffres viennent d’un export daté ; seule l’interface de votre raid confirme l’extraction active.

03 Transitions

Les liens connus entre raids

Un transit mène vers un autre lieu sans quitter nécessairement le raid. Ce graphe ne dessine que des liens pour lesquels une source a été consultée ; il n’est pas exhaustif.

Sortie du raid ≠ transit

Après un transfert, la destination, l’horloge, l’inventaire ou les règles du raid peuvent continuer ; la liste d’extractions affichée dans votre client reste la référence.

05 Fiabilité des informations

  • Source officielleBattlestate Games — patch 1.1.5.0 ↗

Ce n’est pas une note de patch ni un tableau de sorties par mode.
