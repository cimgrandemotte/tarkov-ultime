01 Matrice client / serveur

Installer des composants compatibles

Project Fika est un mod communautaire au-dessus de SPT, distinct du mode coop officiel PvE d’EFT.

Deux numéros de release différents ne sont pas une paire à deviner.

Au relevé du 18 novembre, le plugin Fika 2.4.6 et le serveur Fika C# 2.4.2 sont deux composants distincts. Les fiches les associent à SPT 4.1.6; le tag client annonce EFT 0.16.9.40743. Consulte la documentation Fika et ses deux releases ensemble avant d’installer.

02 Session privée

Base propre, versions alignées, test limité

La doc Fika demande d’obtenir d’abord un SPT fonctionnel sans mods, puis d’ajouter les composants réseau.

  1. Valide SPT seul. Lance un profil propre sans mods jusqu’au menu du jeu.
  2. Lis la page d’installation Fika. Vérifie que les builds sont compatibles; télécharge plugin et composant serveur depuis les releases officielles du projet.
  3. Installe le plugin et le serveur avec l’installeur et les emplacements indiqués par la documentation. Démarre le serveur et confirme que Fika est chargé avant d’ajouter d’autres mods.
  4. Aligne les participants. Tous utilisent le même build SPT/Fika et vérifient leurs dépendances. Commence par une session de test courte.
  5. Ajoute les mods progressivement. Sauvegarde les profils; un mod solo peut ne pas synchroniser ses données en coop.

Dans le raid

Les joueurs hôtes et invités rejoignent une même session pour combattre l’IA et faire progresser certaines activités ensemble. Le comportement détaillé dépend du mod et de ses paramètres.

Après la session

Contrôle chaque profil local. Ne promets pas que tout l’inventaire, toutes les tâches ou chaque mod sont synchronisés de la même façon; la documentation et les options du serveur font foi.

03 Réseau & limites

Garder la session entre personnes de confiance

Fika n’est pas le PvP EFT ni un service public officiel. Les restrictions de licence et de réseau viennent de la documentation Fika.

Pas de matchmaking global

Seuls les joueurs reliés au même serveur peuvent créer ou rejoindre les raids Fika. Le projet dit que Fika est conçu pour des amis de confiance et déconseille fortement l’hébergement public.

Ne publie pas ton adresse IP ni tes identifiants. Partage les détails de connexion uniquement avec le groupe prévu.

Réseau et sécurité

La documentation décrit le réseau serveur-client et, selon le mode d’hébergement, des exigences de routeur/pare-feu. Si tu configures un accès réseau, suis les pages officielles, limite l’exposition et n’ouvre pas de ports au hasard.

Stabilité de l’hôte, CPU et mémoire influencent l’expérience; aucune performance n’est garantie par un simple réglage.

Pourquoi une connexion peut échouer ?

Vérifie d’abord le serveur SPT, le build et les versions client/serveur. Ensuite, contrôle le pare-feu du réseau privé et la documentation Fika. Les choix de NAT/port-forwarding changent selon le réseau; évite un serveur public ou l’envoi d’IP à des tiers non fiables.
