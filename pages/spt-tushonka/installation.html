01 Préparer

Garder l’installation live intacte

L’installation recommandée est une copie séparée. Lance d’abord EFT officiel pour vérifier que le client et ses fichiers sont opérationnels.

01

Une copie EFT légitime

Mets EFT à jour via le launcher BSG ou Steam, lance-le jusqu’au menu et ferme-le. Ne remplace pas ton dossier live par SPT.

02

Un emplacement neuf

Choisis un dossier vide, séparé du jeu live et hors d’un emplacement protégé. Vérifie l’espace libre demandé par l’installateur.

03

Une sauvegarde avant changement

Avant une mise à jour d’une installation existante, copie le dossier de profil et les configurations de mods depuis le dossier SPT concerné.

04

Le runtime de la release

SPT 4.1.6 liste .NET Desktop Runtime 10.0.9 et ASP.NET Core Runtime 10.0.9. Installe uniquement les prérequis indiqués par la release sélectionnée.

Aucun fichier de jeu n’est redistribué ici.

Télécharge l’installateur à partir du lien The Forge / SP-Tushonka et respecte les conditions de l’installation officielle EFT.

02 Installation recommandée

Installer la stable en quatre contrôles

Les références exactes pour ce guide sont SPT 4.1.6, le build EFT requis et deux runtimes .NET.

Stable · recommandée pour jouer

SPT 4.1.6 (40743)

  1. Vérifie que ta copie EFT correspond au build 0.16.9.5.40743 demandé dans la release.
  2. Récupère l’installateur SP-Tushonka v3.0.0.0 depuis le canal officiel du projet; choisis le miroir proposé ou garde le mode automatique.
  3. Choisis un dossier vide à part, puis lance l’installation et lis les avertissements de l’installateur. La v3.0.0.0 annonce également un installateur Linux natif.
  4. Démarre SPT.Server et attends le message de démarrage réussi; ensuite ouvre SPT.Launcher, crée un profil local et lance une première fois sans mods.
  5. Vérifie le menu, quitte proprement, puis sauvegarde le profil avant d’ajouter des mods.

Runtimes requis par 4.1.6 : .NET Desktop 10.0.9 et ASP.NET Core 10.0.9. La valeur affichée par le launcher et la release active font foi.

03 Branche expérimentale

Si tu veux contribuer à un test

Ces instructions ne sont pas une recommandation de jeu grand public. Ne télécharge pas d’archive BE depuis un miroir non contrôlé.

Tests seulement · pas de support

Bleeding Edge 5.0 n’a pas d’installateur stable

Le wiki du projet dit explicitement que cette branche sert aux tests, déconseille son usage casual et n’assure pas de support communautaire normal.

  • Garde le client live intact et fais une copie complète dans un nouveau dossier.
  • Utilise uniquement l’archive BE associée au build live exact indiqué par l’équipe; si le live a évolué, attends une archive compatible.
  • La procédure officielle n’utilise ni l’installateur SPT stable ni un downgrade patcher.
  • Un paquet NuGet 5.0.0-pre.202611061606 est un composant prérelease, pas une preuve de distribution stable.

04 Mettre à jour

Faire une sauvegarde avant le remplacement

Les règles de mise à jour évoluent; cette page résume le guide de branche relevé le 18 novembre 2026.

Patch dans la même branche mineure

  1. Ferme jeu, launcher et serveur.
  2. Copie le dossier du profil et les réglages que tu veux préserver.
  3. Utilise l’archive de mise à jour indiquée par SP-Tushonka; remplace les fichiers de base selon le guide.
  4. Actualise seulement les mods déclarés compatibles avec la version cible, puis démarre d’abord sans mod en cas d’erreur.

Changement majeur ou mineur

Le guide distingue les composants de patch des changements majeurs/mineurs : une nouvelle installation séparée est requise pour changer de branche, par exemple 4.0.x vers 4.1.x. Ne déplace pas le vieux dossier de jeu à la place d’un backup.

Un profil peut être compatible sans que ses mods le soient; le projet ne promet pas la compatibilité de tout profil moddé.

La mise à jour de SPT n’est pas le patch du jeu live. Suis la page officielle Updating SPT ↗ pour la version choisie.
